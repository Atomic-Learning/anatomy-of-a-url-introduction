A URL (Uniform Resource Locator) is the address used to access resources on the internet. It can have several components, each conveying different information. For example, consider the following URL:

https://www.example.com/about-us

This page breaks down the components of this URL. It is a simple example, and more complex URLs can include additional parts.

Protocol

The protocol (also called the scheme) tells your browser which rules to use when requesting a resource. In this case, https stands for Hypertext Transfer Protocol Secure. The :// that follows is URL syntax, and HTTPS means data is encrypted in transit.

Subdomain

A subdomain is an optional label to the left of the main domain name. In this example, www is the subdomain in www.example.com. Subdomains are often used to organise services, such as blog.example.com or api.example.com. Many sites also work without a subdomain.

Domain Name

The domain name identifies the site you want to reach. In this example, example.com is the domain name (often called the registered domain). It is made up of a second-level domain (example) and a top-level domain (.com).

Path

The path identifies the specific page or file being requested. In this example, /about-us points to the site's "About Us" page. The readable part of the path (about-us) is often called a "slug" - a URL-friendly version of the page name.
